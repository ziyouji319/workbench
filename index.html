📖 第一次使用？Supabase 免费数据库部署（国内可访问，无需 VPN）
  1. 注册：打开 supabase.com，点 Start your project，用邮箱或 GitHub 登录。
  2. 建项目：点 New project，Name 填 workbench，设一个数据库密码（记好），Region 选 Southeast Asia (Singapore)，点 Create，等 1-2 分钟。
  3. 建表：进项目后，左侧 SQL Editor → 点 New query → 粘贴下方 SQL → 点 Run。
  4. 抄密钥：左侧 Settings → API，复制 Project URL 和 anon public key。
  5. 填回本页：把 URL 和 anon key 粘贴到上方两个输入框，点「保存并连接」。

💡 配置一次后，手机和电脑填同一个 URL 和 key，数据自动合并同步。相比 Cloudflare，Supabase 在国内访问更稳定。

同步逻辑

· 每个站点有独立的私有数据行，不同用户之间互不串数据 · 打开应用时自动拉取云端数据并合并（同一条记录以最近修改的为准）
· 每次新增/修改灵感或项目后，自动推送云端（几秒内）
· 在「云同步」页点「立即同步」可手动强制合并一次
